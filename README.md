# Netmaster redesign prototype

A responsive one-page PHP prototype using Bootstrap 5 for layout utilities and custom CSS for the visual identity.

## Run locally

```powershell
php -S 127.0.0.1:8080 -t outputs/netmaster-redesign
```

Then open `http://127.0.0.1:8080`.

The contact form currently validates input and shows a confirmation. Connect the success branch in `index.php` to SMTP or the final CRM before launch.
